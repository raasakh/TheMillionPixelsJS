# The Million Pixels Homepage - Node.js версия

Веб-приложение для продажи пикселей с поддержкой загрузки изображений.

## 🚀 Возможности

- 📍 Размещение пикселей на сетке 1000×1000
- 🖼️ Поддержка загрузки изображений (JPG, PNG, GIF, WebP, BMP, SVG)
- 🔧 Админ-панель с полным управлением
- 🔐 Аутентификация администратора
- 🔍 Поиск и фильтрация пикселей
- 📊 Статистика и мониторинг
- 📱 Адаптивный дизайн
